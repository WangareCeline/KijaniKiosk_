Summary
============================================================
All five credential audit checks passed. No credentials (passwords,
tokens, or API keys) were found in:
  - The current or any historical version of the Jenkinsfile
  - The .npmrc file (which was never committed to git)
  - The saved build log output

The Nexus credential used by the pipeline is stored exclusively within
Jenkins' encrypted credential store and is injected into the pipeline
at runtime via withCredentials, scoped only to the Publish stage, and
is never written to disk outside of the single shell step that
generates and immediately deletes .npmrc.
